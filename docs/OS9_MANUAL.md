# OS-9 ユーザマニュアル

Tang Nano 9K (FPGA) と `sim09` (シミュレータ) で動く **OS-9 (NitrOS-9 Level 1)** の、はじめての人向けの使い方です。
コマンドの打ち方、ファイルの扱い方、日本語ワープロ `jwp`、困ったときの対処をまとめました。
FPGA ボードそのものの話 (ビットストリーム、フラッシュ、SD カードの書き方) は [FPGA.md](FPGA.md) にあります。

> この文書の例は、実機とシミュレータで動かして確かめた出力です。確かめていないことは、そう書いてあります。

## 1. OS-9 とは

OS-9 は、Microware 社が 1980 年に作った、6809 CPU 用の OS です。小さな機械で、**複数のプログラムを同時に動かせる**ことと、
**UNIX に似た使い方** (コマンドを打つ、ファイルとディレクトリ、リダイレクト、パイプ) ができることが特徴です。
ここで使うのは、そのオープンソースの子孫 **NitrOS-9 の Level 1** です。

| 項目 | このシステムの OS-9 |
|---|---|
| CPU | MC6809 (FPGA 上のコア、またはシミュレータ) |
| メモリ | 64KB (うち、プログラムが使える空きは約 44KB = 175 ページ) |
| 使う人 | 1 人 (ログインはありません。起動するとすぐにシェル) |
| ディスク | `/d0` (カードの先頭にある OS-9 のディスク)、`/d1` (2 台目。SKK の辞書など) |
| 画面 | USB のシリアル (UART、115200 baud) と、HDMI の画面の**両方**に同じ内容が出る |
| 文字コード | UTF-8 (日本語が使えます) |

Level 1 は、64KB の中に、OS 本体も、コマンドも、データも入ります。大きなプログラムは、同時には動かせません (14 章)。

## 2. 起動する

### 2.1 実機 (Tang Nano 9K)

1. **カードに OS-9 のディスクが入っていること**を確かめます (`os9/OS9.dsk` を書いたもの。書き方は [FPGA.md](FPGA.md))。
2. カードをボードのスロットに差して、USB ケーブルで PC (または電源) につなぎます。HDMI のモニタをつなぐと、同じ画面が出ます
   (**モニタには直結してください。KVM スイッチ経由だと映らないことがあります**)。
3. PC から操作するには、シリアルの端末ソフトを開きます。

```
minicom -D /dev/ttyUSB2 -b 115200       (番号は環境で変わります。ls /dev/serial/by-id/ で、末尾が if01 の方)
```

   端末の設定は **115200 baud、8 ビット、パリティなし、ストップ 1、フロー制御なし、文字コード UTF-8** にします
   (minicom は、`Ctrl-A` のあと `O` の「Serial port setup」で、ハードウェアとソフトウェアのフロー制御を **No** にします)。
4. 電源を入れてから約 15 秒で、次のように表示されます。

```
NitrOS-9/6809 Level 1 V1.0.1
Tang Nano 9K
(C) 2014 The NitrOS-9 Project

http://www.nitros9.org


Shell

OS9:
```

`OS9:` が **プロンプト** (コマンドを待っている印) です。ここにコマンドを打ちます。

> 起動の様子は、ボードの LED でもわかります (LED0 が点滅 = 動作中、LED1 点灯 = 起動処理が済んだ、LED2 点灯 = カードの初期化が済んだ、LED3 = カードのアクセス中、LED4 点灯 = カードの失敗、LED5 点灯 = 止まった)。
> 15 秒待っても `OS9:` が出ないときは、13 章を見てください。

### 2.2 シミュレータ

```
./sim09 -rom fuzix/images/bootrom.bin -0 os9/OS9.dsk                       (カードと同じ起動のしかた)
./sim09 -rom os9/os9v1.rom -0 os9/OS9.dsk -1 os9/WORK.dsk -v os9/level1    (ROM に OS 全体がある版。/v0 でホストのディレクトリが見える)
```

シェルを終わるには、`shutdown` (10 章)。

## 3. はじめての操作

### 3.1 コマンドを打つ

`OS9:` に続けて、コマンドと、必要なら引数を打って、`Enter` を押します。

```
OS9:date
```

* **大文字と小文字は区別されません** (`DIR` も `dir` も同じです)。
* コマンドの名前のあとに、空白を置いて、引数 (ファイル名など) を並べます。

### 3.2 最初にすること: `chx /d0/cmds`

コマンドは、ディスクの `/d0/cmds` というディレクトリに入っています。OS-9 は、コマンドを「**実行ディレクトリ**」から探すので、
起動したら、まず次を実行してください。

```
OS9:chx /d0/cmds
```

これをしないと、`dir` などを打っても、`ERROR #216` (見つからない) になります。**毎回の起動のあとに、1 回**です。

### 3.3 打ち間違えたとき (行の編集)

| キー | 動作 |
|---|---|
| `Backspace` (または `Ctrl-H`) | 1 文字消す |
| `Ctrl-X` | 入力中の行を全部消す |
| `Ctrl-A` | 直前に打った行をもう一度出す (直してから `Enter`) |
| `Ctrl-R` | 入力中の行を表示し直す |
| `Ctrl-C` | 実行中のコマンドに割り込む (中断する) |
| `Ctrl-E` | 実行中のコマンドを強制的に終わらせる |
| `Ctrl-D` | 入力の終わり (ファイルの終わり) |
| `Ctrl-W` | 画面の出力を、いったん止める / 続ける (`tmode pause` を有効にしたとき、画面が 1 ページ (24 行) ごとに止まります) |

`Backspace` で文字が消えないときは、`Ctrl-H` を使うか、端末の設定でバックスペースを `^H` にしてください。
これらは `tmode` コマンドで見られます (`tmode` を打つと、`del=18 eor=0D eof=04 reprint=12 dup=01 psc=17 abort=03 quit=05 bse=08` などと出ます。数字は 16 進で、`18` = `Ctrl-X`)。

### 3.4 試してみる

```
OS9:chx /d0/cmds
OS9:echo Hello
Hello
OS9:display 41 42 43 0d
ABC
OS9:dir /d0
 Directory of /d0  00:44:28
OS9Boot   CMDS      SYS
DEFS      startup   RUN32
RUN51
```

* `echo` は、続く文字をそのまま表示します。
* `display` は、16 進で与えた文字コードを表示します (`41` = `A`、`0d` = 改行)。
* `dir` は、ディレクトリの中のファイルを一覧します。

## 4. ディスクとファイル名

### 4.1 ディスクとデバイス

OS-9 の「パス名」は、**`/` から始めて、デバイスの名前、ディレクトリの名前、ファイルの名前**を `/` でつなぎます。

| 名前 | 意味 |
|---|---|
| `/d0` | ドライブ 0: OS-9 のディスク (カードの先頭にあるもの) |
| `/d1` | ドライブ 1: 2 台目のディスク (カードの 128MB の位置)。SKK 辞書や作業用のディスク |
| `/term` | 端末 (キーボードと画面。UART と HDMI) |

```
/d0/cmds/dir         ドライブ 0 の cmds ディレクトリにある dir というファイル
```

### 4.2 ディレクトリ

ディレクトリは、ファイルを入れる「入れ物」です。ディスクの一番上のディレクトリを**ルート**と呼びます (`/d0` がルート)。
`/d0/cmds` はルートの中の `cmds` ディレクトリです。

* `.` は「今いるディレクトリ」、`..` は「1 つ上のディレクトリ」です。
* パス名が `/` で始まらないと、**今いるディレクトリ (データディレクトリ)** からの相対になります。

### 4.3 データディレクトリと実行ディレクトリ

OS-9 には、**2 つ**の「今いるディレクトリ」があります。

| もの | 何に使う | 変える命令 |
|---|---|---|
| データディレクトリ | ファイル名 (`list memo`) を探す場所 | `chd` |
| 実行ディレクトリ | コマンド (`dir`、`copy`) を探す場所 | `chx` |

起動した直後は、データディレクトリは `/d0`、実行ディレクトリは**何もない**ので、`chx /d0/cmds` が要ります。

### 4.4 ファイル名の決まり

* 長さは 29 文字まで。
* 使える文字: 英字、数字、`_` (下線)、`.` (ピリオド)、`$`、`-`。**空白と日本語は使えません**。
* 大文字・小文字は区別されません (表示は、打ったとおりに残ります)。

## 5. ファイルを扱う

以下の例は、`chx /d0/cmds` を済ませたあとのものです。

### 5.1 ディレクトリを作る・移る

```
OS9:makdir /d0/memo            ディレクトリ memo を作る
OS9:chd /d0/memo               データディレクトリを memo にする
OS9:dir                        今のディレクトリの中身 (まだ空)
OS9:chd /d0                    ルートに戻る
```

### 5.2 テキストファイルを作る

(1) `build` で、1 行ずつ打つ (最後は空行):

```
OS9:build hello
? Hello, OS-9
?
```

(2) `echo` と `>` で、1 行のファイルを作る:

```
OS9:echo test > t1
```

(3) 日本語の文章を書くなら、ワープロ `jwp` が便利です (8 章)。

### 5.3 中身を見る

```
OS9:list hello                 ファイルの中身を表示する
Hello, OS-9
OS9:dump hello                 16 進ダンプで見る
     0 1 2 3 4 5 6 7  0 2 4 6
ADDR 8 9 A B C D E F  8 A C E
==== +-+-+-+-+-+-+-+- + + + +
0000 48656C6C6F2C204F Hello, O
0008 532D390D         S-9.
```

OS-9 のテキストファイルの行の終わりは、改行 (LF) ではなく **CR (`0D`)** です。

### 5.4 コピー・名前の変更・削除

```
OS9:copy hello hello2          hello を hello2 という名前でコピー
OS9:rename hello2 world        名前を world に変える
OS9:del world                  ファイルを消す (消すと戻せません)
OS9:deldir /d0/memo            ディレクトリを、中身ごと消す (注意)
```

`copy` で、すでにある名前のファイルへコピーしようとすると、`ERROR #218` (すでにある) になります。先に `del` してください。

### 5.5 空き容量を調べる

```
OS9:free /d0
"DRAGON DISK" created on: 83/10/31
Capacity: 736 sectors (1-sector clusters)
41 Free sectors, largest block 10 sectors
```

1 セクタは 256 バイトです。**この `/d0` の空きは、41 セクタ (約 10KB) しかありません** (OS-9 のコマンドなどで、ほとんど埋まっています)。
たくさんのファイルを作りたいときは、`/d1` に作業用のディスク (`os9/WORK.dsk`、180KB) を置いてください ([FPGA.md](FPGA.md))。

### 5.6 ファイルの属性

```
OS9:attr hello
----r-wr
```

8 文字は、左から `d` (ディレクトリ)、`s` (共有不可)、`pe` `pw` `pr` (一般の人の 実行・書き込み・読み出し)、`e` `w` `r` (所有者の 実行・書き込み・読み出し) の順で、付いているものは文字、付いていないものは `-` です。
プログラム (実行できるファイル) を作ったときは、`attr ファイル名 e pe r pr` で、実行できる印 (`e` と `pe`) を付けます。

## 6. シェルの使い方

`OS9:` に出ているのが、**シェル**です。コマンドを組み合わせる機能があります。

| 書き方 | 意味 | 例 |
|---|---|---|
| `コマンド > ファイル` | 出力を、画面ではなくファイルへ | `echo test > t1` |
| `コマンド < ファイル` | 入力を、キーボードではなくファイルから | `list < t1` |
| `コマンド1 ; コマンド2` | 続けて実行する | `echo a; echo b` |
| `コマンド1 \| コマンド2` | パイプ: 1 の出力を、2 の入力にする | `dir /d0 \| list` |
| `コマンド &` | **バックグラウンド**で実行 (終わりを待たずに、次を打てる) | `sleep 100 &` |

`sleep 100 &` を打つと、`&003` のように、プロセスの番号が表示されて、すぐにプロンプトが戻ります (7 章)。
OS-9 のシェルには、`*` のようなワイルドカードはありません (ファイル名は、1 つずつ書きます)。

## 7. 動いているもの (プロセスとメモリ)

OS-9 では、動いているプログラムを**プロセス**と呼びます。

```
OS9:procs
Usr #  id pty sta mem pri mod
----- --- --- --- --- -------
    0   2 128 act   3 Shell
    0   1 128 wai   1 SysGo
    0   3 128 sle   2 Sleep
```

* `Shell` が今のシェル、`SysGo` が最初に起動されたプロセスです。`Sleep` は、バックグラウンドで動かしたものです。
* `sta` (状態): `act` は動いている、`wai` は子の終わりを待っている、`sle` は眠っている。
* `mem` はそのプロセスが使っているメモリ (ページ数、1 ページ = 256 バイト)。

```
OS9:mdir                       メモリにある「モジュール」(プログラムの部品) の一覧
OS9:mfree                      空きメモリ
 Address  pages
--------- -----
 B00-B9FF  175
BC00-BCFF    1
Total pages free = 176
```

OS-9 では、プログラムも、ドライバも、**モジュール**という単位です。`mdir` に出る名前は、メモリに入っているモジュールです。
`mfree` の `175` は、連続した空きのページ数で、**1 つのプログラムは、この中に収まる必要があります** (`jwp` は約 174 ページ使います)。

## 8. 日本語を使う: `jwp`

`jwp` は、OS-9 の上で動く、**全画面の日本語ワードプロセッサ**です。

```
OS9:chx /d0/cmds
OS9:jwp memo.txt               memo.txt を開く (なければ新規)
```

| キー | 動作 |
|---|---|
| `Ctrl-S` | 保存 |
| `Ctrl-Q` | 終了 (変更していれば確認) |
| `Ctrl-W` | 名前を付けて保存 |
| `Ctrl-O` | 別のファイルを開く |
| `Ctrl-R` / `Ctrl-T` | 検索 / 次を検索 |
| `Ctrl-K` / `Ctrl-Y` | 行末まで切り取り / 貼り付け |
| `Ctrl-L` | 画面の描き直し |
| `Ctrl-J` | かな入力 (SKK) |

* 日本語は、端末の日本語入力 (IME) で打てます。
* **`jwp` の中だけで日本語を入力する (SKK)**: `Ctrl-J` を押すと、ローマ字がひらがなになります。**大文字で始める**と変換の対象になります。
  `Kanji` と打って `Space` で「漢字」に変換、`Enter` で確定します。辞書は `/d1/skk.dic` にあります (カードの 128MB の位置に、辞書のディスクが要ります。[FPGA.md](FPGA.md))。
* `jwp -v` でバージョンが出ます (`jwp 1.0 (c) 2026 YUKARI Semiconductor Devices`)。

キーの全部、折り返しの規則、整形出力などは [JWP.md](JWP.md) にあります。

> `jwp` は、メモリを多く使います。ほかのプログラムをバックグラウンドで動かしていると、`ERROR #207` (メモリが足りない) で起動できないことがあります。

## 9. ほかのプログラム: `dhry`、`shutdown`

### 9.1 `dhry` (ベンチマーク)

```
OS9:dhry -t 10                 10 秒 (OS-9 の時間で) 以上、計測する
Dhrystone checks OK
Runs:                  2090
Time:                  10 s
Microseconds for one run through Dhrystone: 4784
Dhrystones per second: 209
```

Dhrystone は、整数演算の速さを測る、古典的なベンチマークです。実機で 209 Dhrystones/s でした (シミュレータは 210)。
`dhry` は OS-9 の時計で秒数を測ります。その時計も CPU の速さに合わせて進むので、実時間の速さを表す値ではありません。詳しくは [DHRYSTONE.md](DHRYSTONE.md)。

### 9.2 `shutdown` (止める)

10 章を見てください。

## 10. 止める

**電源を切る前に、`shutdown` を実行してください。**

```
OS9:shutdown
System halted.
```

`System halted.` と出て、CPU が止まります (実機では、ボードの LED5 が点きます)。そのあとで USB を抜く (電源を切る) と安全です。
`jwp` などで編集中のファイルは、**先に保存して終了してから**、`shutdown` します。

OS-9 のディスクの書き込みは、1 回ごとに完了するので、`shutdown` を忘れても、ふつうは壊れません。ただし、ファイルを書いている最中に電源を切ると、
そのファイルは壊れることがあります。

## 11. コマンド一覧

`/d0/cmds` に入っているコマンドです。★は、このシステムで動かして確かめたもの、それ以外は、標準的な OS-9 のコマンドで、試験していないものです。

**ファイルとディレクトリ**

| コマンド | 働き |
|---|---|
| ★ `dir` | ディレクトリの一覧 |
| ★ `list` | ファイルの中身を表示 |
| ★ `copy` | ファイルのコピー |
| ★ `rename` | ファイル名を変える |
| ★ `del` | ファイルを消す |
| ★ `makdir` | ディレクトリを作る |
| `deldir` | ディレクトリを中身ごと消す |
| ★ `build` | テキストファイルを作る (1 行ずつ入力) |
| ★ `dump` | 16 進ダンプ |
| ★ `attr` | ファイルの属性を表示・変更 |
| ★ `free` | ディスクの空き容量 |
| `cmp` | 2 つのファイルを比べる |
| `merge` | ファイルをつなげる |
| `tee` | 入力を、画面とファイルの両方へ |

**ディスクの管理** (ディスクの中身を壊す恐れがあるので、使うときは、よく確かめてください)

| コマンド | 働き |
|---|---|
| `format` | ディスクを初期化する (**中身が消えます**) |
| `backup` | ディスクをコピーする |
| `dcheck` | ディスクの整合性を調べる |
| `dsave` | ディレクトリごとコピーするための命令を作る |
| `verify` | モジュールの検査 |
| `os9gen` `cobbler` | 起動ファイル (`OS9Boot`) を作る |

**システムの情報とプロセス**

| コマンド | 働き |
|---|---|
| ★ `procs` | 動いているプロセスの一覧 |
| ★ `mdir` | メモリにあるモジュールの一覧 |
| ★ `mfree` | 空きメモリ |
| ★ `ident` | モジュールの情報 (名前、大きさ、版、検査値) |
| ★ `date` | 日付 (`date t` で時刻つき) |
| `setime` | 時刻を設定する |
| ★ `sleep` | 指定した tick 数だけ待つ (`sleep 100 &` でバックグラウンドの練習に使えます) |
| ★ `echo` `display` | 文字を表示する |
| ★ `tmode` | 端末の設定を表示・変更 (`tmode pause` など) |
| `xmode` | デバイスの設定の変更 |
| `link` `unlink` `load` `save` | モジュールをメモリに入れる・外す・ファイルに保存する |
| `printerr` | エラーメッセージの表示の設定 |
| `pwd` `pxd` | 今のデータディレクトリ・実行ディレクトリの表示 (このシステムでは何も表示されませんでした) |

**プログラム**

| コマンド | 働き |
|---|---|
| ★ `jwp` | 日本語ワードプロセッサ (8 章) |
| ★ `dhry` | Dhrystone ベンチマーク (9 章) |
| ★ `shutdown` | 止める (10 章) |
| `shell` | もう 1 つのシェルを起動する |
| `login` `tsmon` | ユーザの認証・端末の監視 (このシステムでは使いません) |
| `binex` `exbin` | モトローラ S レコードとバイナリの変換 |
| `RUNB` | BASIC09 の実行用 (BASIC09 の本体は入っていません) |
| `go51` `acia51` | sbc09 のシステム固有 (使い方は、`os9/level1/cmds` のソースを見てください) |

## 12. エラー番号

OS-9 は、失敗すると `ERROR #番号` を出します。主なものです。

| 番号 | 意味 | よくある原因 |
|---|---|---|
| 207 | プロセスのメモリがいっぱい | プログラムが大きすぎる。バックグラウンドで動かしているものがある (`procs`、`mfree` で確認) |
| 211 | ファイルの終わり | 読み終わった (エラーではありません) |
| 214 | ファイルにアクセスできない | 属性の問題。実行できない (`e` がない) ファイルを実行しようとした |
| 215 | パス名が正しくない | 引数が足りない (`list` だけ打った)。空白や使えない文字が入っている |
| 216 | パス名が見つからない | ファイル名の打ち間違い。`chx /d0/cmds` をしていないでコマンドを打った |
| 218 | すでに存在するファイルを作ろうとした | `copy` の先に同じ名前のファイルがある |
| 221 | モジュールが見つからない | `link` や `load` の名前の間違い |
| 237 | システムのメモリがない | 一度に多くのプロセスを起動した |
| 238 | ディレクトリが空ではない | 中身のあるディレクトリを消そうとした (`deldir` を使います) |
| 244 | 読み出しの失敗 | ディスクの読み出しに失敗した (カードの接触、イメージの不良) |
| 245 | 書き込みの失敗 | ディスクの書き込みに失敗した |

番号のあとに、メッセージの名前が出るようにするには、`printerr` を使います (このシステムでは試験していません)。

## 13. 困ったときは

| 症状 | 見ること |
|---|---|
| 電源を入れても `OS9:` が出ない | ① カードが OS-9 のディスクか (FUZIX や MK09 のカードでは、その OS が起動します)。② HDMI の画面には出ているか (出ていれば、端末ソフトの設定の問題です)。③ 起動に約 15 秒かかります |
| 画面 (minicom) に何も出ない・文字化けする | ① 端末の設定 (115200、8N1、**フロー制御なし**)。② デバイス名 (`ls /dev/serial/by-id/` の `if01`)。③ 端末ソフトを 2 つ同時に開いていないか (バイトを取り合って、文字が欠けます)。④ USB を、いったん抜き差しする |
| HDMI の画面が真っ暗 | **KVM スイッチやスプリッタを通していないか** (直結してください)。モニタが 640x480 を受け付けるか |
| `ERROR #216` ばかり出る | `chx /d0/cmds` を、最初に実行したか |
| `date` の年が `19126` と出る | 古い `date` コマンドが、2000 年以降の年を `19` + 126 のように表示するためです。時計そのものは 2026 年です |
| 時刻が合っていない | 時計には電池がありません。ビルド (シミュレータではホスト) の日時から数えます |
| `jwp` が `ERROR #207` | メモリ不足です。`procs` で、バックグラウンドのプロセスを確認して、終わらせてください |
| 日本語が文字化けする | 端末が UTF-8 か。`jwp` のメッセージが日本語で出るか |
| `OS9:` の後ろに、変な文字が出る | USB を挿し直す |
| 起動の途中で止まる | カードの OS-9 のディスクが壊れていないか (`dd` で書き直す)。カードを、いったん抜いて挿し直す。LED4 が点いていれば、カードが読めていません |

## 14. このシステムの制限

* **メモリは 64KB** です。OS の本体とコマンド、データがすべて入ります。大きなプログラムは動きません。
* **ディスクの空きは少ない**です (`/d0` は約 10KB)。たくさんのファイルを作るなら、`/d1` に作業用のディスクを置きます。
* ユーザは 1 人です。ログインやパスワードはありません。
* **時計に電池はありません**。電源を入れるたびに、ビルドの日時から数え始めます。`setime` の効き方は、試験していません。
* 日本語のファイル名は使えません (ファイルの**中身**は、UTF-8 で日本語を書けます)。
* ほかのコンピュータとファイルをやりとりする専用の手段は、実機にはありません (ホストのディレクトリを見せる `/v0` は、シミュレータだけです)。
  ファイルを取り出すときは、カードを PC に挿して、ディスクイメージを読む方法になります。
