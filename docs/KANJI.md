# 日本語処理

OS-9 (6809) の SCF は 8 ビットクリーンなので、バイト列としては日本語をそのまま通せます。
そこで次の 4 点を実装しています。

## 1. コンソールの文字コード変換 (`-kanji`, `-hostcs`)

ホスト端末の文字コード (`-hostcs`、既定はロケール `LANG`/`LC_CTYPE` から) とゲストの文字コード (`-kanji`) が違うときは
`iconv(3)` でストリーム変換します。複数バイト文字が読み込みの途中で切れても壊れません。

| `-kanji` | ゲスト | 備考 |
|---|---|---|
| `raw` (既定) | 端末と同じ | 変換なし。ROM の文字コード設定 (下記) を端末に合わせること |
| `utf8` | UTF-8 | |
| `euc` | EUC-JP | 半角カナ (`8E xx`) と補助漢字 (`8F xx xx`) を含む |
| `sjis` | Shift_JIS (CP932) | 半角カナは 1 バイト |

ネットワークの telnet 端末 (`/n1`..) も同じ設定で変換します (telnet クライアントは UTF-8 でよい)。

## 2. 複数バイト文字を理解する行編集 (SCF の改造)

`os9/kanji/scf.asm` は NitrOS-9 の `scf.asm` の改造版です。パス記述子の PD.PAR (SCF ドライバでは未使用の
パリティコード) を端末の文字コードとして使います。

| PD.PAR | 意味 |
|---|---|
| 0 | 従来どおり (1 バイト = 1 文字) |
| 1 | UTF-8 |
| 2 | EUC-JP |
| 3 | Shift_JIS |

PD.PAR が 1〜3 のとき、バックスペース (と行削除) は**1 文字分**をバッファから削除し、画面の消去シーケンス
(`BSE` または `BSE,SP,BSE`) を**表示桁数の回数**だけ出力します (全角漢字・かな = 2 桁、ASCII・半角カナ = 1 桁)。
文字境界は行バッファの先頭から前方に走査して求めるので、Shift_JIS の下位バイトが ASCII 範囲でも誤りません。

ROM は端末デスクリプタ `TERM` / `N1`..`N3` の既定値だけが違う 3 種類を用意しています。

| ROM | PD.PAR の既定 |
|---|---|
| `os9v1.rom` / `os9v2.rom` | 1 (UTF-8) |
| `os9v1_euc.rom` / `os9v2_euc.rom` | 2 (EUC-JP) |
| `os9v1_sjis.rom` / `os9v2_sjis.rom` | 3 (Shift_JIS) |

実行中の切り替えは `kmode` コマンドです。

```
OS9:kmode            現在の設定を表示
OS9:kmode euc        EUC-JP にする (off | utf8 | euc | sjis)
```

## 3. 日本語ファイル名 (`-kname`)

`-kname` を付けると `/v0` (ホストのディレクトリ) の 8 ビットのファイル名を使えます。

* パス名の終端は空白・CR・NUL で、OS-9 の「最後の文字の bit 7」という慣習は使いません。
* ホストの名前とゲストの文字コードは `-hostcs`/`-kanji` に従って相互変換されます
  (例: ホストの UTF-8 `日本語.txt` が EUC-JP のゲストには EUC-JP のバイト列で見える)。
* `dir` は `os9/kanji/dir.asm` に差し替え済みです。VRBF に私用の GetStat `SS.KNm ($B0)` を問い合わせ、
  8 ビット名のときは終端マーカーなしで NUL までを名前として表示します。通常の RBF (`/d0`) では従来どおりの表示です。
  カラムの揃えはバイト数基準です。
* ファイルの**内容は変換しません** (バイト列のまま)。`list` の表示は端末の文字コードに従います。

## 4. 動作確認

`tests/os9_test.py` が Level 1/2 x (UTF-8 / EUC-JP / Shift_JIS) で次を確認します。

* 日本語ファイル名の一覧表示、`list`、`copy` (内容がバイト単位で一致)
* `echo あいう<BS><BS>え` が `あえ` になり、消去シーケンスが 1 文字あたり 2 桁分出力される
* `kmode` の表示

`tests/net_test.py` は telnet 端末経由で `こんにちは世界` が往復することを確認します。
