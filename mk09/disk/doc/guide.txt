MK09 かんたんガイド
====================

MK09 は MC6809 用のマイクロカーネルです。電源を入れると SD カードから読み込まれ、
シェルが起動します (/> が出ます)。

シェルのコマンド
  ls [-l] [-a] [場所]   一覧            cat ファイル...   中身を出す
  cd 場所 / pwd         移動 / 今の場所  cp 元 先            コピー
  mv 元 先              名前変更・移動   rm ファイル...      削除 (空のディレクトリも)
  mkdir 名前            ディレクトリ作成 echo 文字...         文字を出す
  date                  日付と時刻       df                  ディスクの空き
  ps                    タスクの一覧     stty                コンソールの設定を見る・変える
  jwp [ファイル]        日本語ワープロ   help                コマンドの一覧
  more ファイル         1画面ずつ見る    grep 文字列 ファイル 合う行を出す
  life                  ライフゲーム (q で終了)  basic [ファイル]  BASIC
  shutdown              電源を切る (シミュレータは終了)

  コマンド > ファイル   出力をファイルに     コマンド >> ファイル   ファイルの終わりに追加
  コマンド < ファイル   入力をファイルから   ^C                    実行中のプログラムを止める

日本語ワープロ jwp
  jwp メモ.txt          ファイルを開く (なければ新規)
  ^S 保存  ^W 別名で保存  ^O 開く  ^R 検索  ^T 次を検索  ^K 行を切り取り  ^Y 貼り付け
  ^X 整形出力  ^Q 終了  ^L 画面を描き直す  ^G 改行形式 (LF/CR/CRLF) の切り替え
  ^J かな入力 (SKK)     かな入力中: 大文字で読みの始まり (Kanji Space で「漢字」)、
                        Space 次の候補、Enter 確定、q カタカナ、l 英数に戻す
  辞書は /SKK/SKK.DIC (ディスクの上のファイルを引くので、メモリは使いません)。
  使った語はユーザ辞書 /SKK/USER.DIC に覚えます。

文字コード
  stty utf8 | euc | sjis   端末の文字コード (起動時に /ETC/RC.SH が設定します)
  ディスク上のファイル名は 8.3 形式 (全角文字は 2〜3 バイトとして数えます)。

くわしくは mk09/docs の MANUAL.md、DESIGN.md、SPEC.md を見てください。
